# Scope, safety and disclosure

- This is a synthetic educational exercise; names, workshop details and source registers are fictional.
- `official_document` is a user-supplied label. The program does not read, verify, authenticate or independently assess source contents.
- A referenced source does not automatically prove the claim it is linked to.
- `human_approved` is untrusted input in this demo; it is not verified identity, authorisation or audit evidence.
- No publishing, payment, account change, web access or other external action occurs.
- The output is a review recommendation only, never an instruction to auto-act.
- The demonstration is not evidence of deployed enterprise autonomy, technical enforcement, business uplift or regulatory compliance.
- No proprietary governance documents, client data, or credentials are required or incorporated.
- Public release requires repository visibility change by its owner following final content inspection.
